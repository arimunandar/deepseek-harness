# @deepseek-ai/dsh-client-ui-settings-connections

[English](README.md) | 中文

"连接你的 AI"页面，构建在宿主端的[连接目录](../../credentials/connections/README.zh.md)之上。每个可用后端一张卡片：产品名、一句话、一个状态词、一个显而易见的按钮。状态词背后的所有技术事实——凭据引用、记录作用域、设置命名空间、提供方路由——都留在宿主端；跨过 wire 的已经是那四种状态以及各自蕴含的那一个修复动作，因此这个页面渲染的是一次账号连接，而不是一份提供方 profile。想要那份 profile 的人应该去模型页；本区块在导航中排在它前面，因为连接账号才是人一进来就带着的问题。

## 不接管首次运行

本包只贡献一个 `settings.section`。`settings.onboarding` 槽位已经有占用者——官方 DeepSeek 凭据步骤——再加一个提出同类问题更宽版本的接管界面，只会让推迟了第一个的人又撞上第二个。哪个步骤拥有首次运行，是关于那条流程的决定，而不是关于本页面的。

卡片动作只绑定一次（`cardActions`），因此未来任何渲染同一张卡片的界面，对同一状态给出的都是同一个修复动作，而不是各自另接一套。

## 登录发生在卡片上，不在对话框里

尝试运行期间，卡片本身变成对话：流程最新的通知、它希望打开的页面、它希望输入的验证码，然后是它的提问和输入框。步骤是流程自己的，所以这里不知道任何提供方的 OAuth 如何运作，而一个流程新增提问的提供方也不需要改动本页面。`secret` 会遮蔽输入框并避开自动填充；`select` 把选项渲染成按钮。在有内容可发送之前"继续"保持禁用，已回答的问题在答案发出之前就被清除，所以没人能把同一个验证码发送两次。

卡片会提示保持页面打开。这不是装饰：一次尝试只活在发起它的进程里，刷新就会放弃它。

## 每种状态都指明自己的修复动作

`not-connected` 提供"连接"，并在检测到厂商自己的命令行工具已安装时补上一句——同一个账号，一次点击，不读取他们的任何文件。`setup-required` 提供"完成设置"。`needs-attention` 提供重新登录，唯独启动环境提供的凭据不提供任何按钮，因为本页面能写的东西都改变不了它。`connected` 提供"用于新对话"，直到它正是当前在用的那个。"断开连接"只对本应用自己存下的东西出现，其确认框指名连接名称，并明确说明这只是忘记一份本地登录，而不是让任何人退出账号。

`not-connected` 不带状态圆点。一个人只是还没选择某个后端，这本身没有任何问题，而那里的彩色圆点会被读成一个待修的故障。

## 收敛

宿主端把每个能改变目录的所有者折叠成一个不带载荷的 `connections/changed`，因此另一个标签页里完成的登录、手工编辑的 `settings.yaml`、在别处删除的凭据，都无需轮询即可收敛；`connection/reset` 在传输重连后重新读取。对话帧单独传递，因为它们属于某一次尝试而不属于目录。每次变更都重新读取整个目录，而不是就地修补某一行：一个连接的状态是四个所有者的联接结果，本地施加的增量只会是本页面对这个联接现在如何回答的猜测。

## Model Experience

None, as this package renders a browser configuration surface; nothing here reaches a model request.

#### KV Cache effect

None; this package neither assembles nor sends a provider request.

## Known Limitations and Deferred Work

- **登录途中刷新就会丢失** —— 尝试在任何地方都不是持久的，所以卡片只能给出提示。恢复它需要一份授权接缝并不具备的存储。
- **尝试运行期间只显示最新一条通知** —— 更早的那些在尝试结束后进入折叠历史。一次说了好几件事的流程，在最要紧的那一刻只显示最后一条。
- **远程浏览器得到的是一个失效页面** —— 目录走宿主端 Remote，因此非 loopback 浏览器什么都读不到，每个按钮都是死的。页面渲染的是它的读取失败，而不是一段专门的解释。
- **首次运行到不了这个页面** —— 没有凭据的人遇到的是官方 DeepSeek 步骤，它问的问题比这里的卡片窄。要走到 Claude 或 Codex，得先找到设置页。要解决这一点，需要先决定哪个步骤拥有首次运行。
- **卡片提供流程的第一种方式** —— 一个流程提供多种登录方式（订阅登录与手输密钥）的后端只会显示第一种。在它们之间选择需要一个本页面没有绘制的控件。
